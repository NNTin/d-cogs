# Credits

This repository mirrors cogs authored elsewhere. Install directly from the source repositories instead of from this mirror.

- `hotreload` — sourced from `cswimr/SeaCogs` (branch `main`). The copy is synced for convenience and is not my creation.
- `assistant` — inspired by `vertyco/vrt-cogs` (branch `main`). Replaced here by `langcore`, `ollama`, `openrouter`, `qdrant`, the `cogchain` module, and extension cogs like `mermaid` and `spoilarr`; inspiration drawn from the original assistant cog.
- `modreload` — a copy of `hotreload` (mod stands for python module). Instead of reloading a cog, it performs a pip install. Created with one prompt; see `modreload/IMPLEMENTATION_PLAN.md`.
